Privacy Policy

Effective date: September 4, 2026

This Privacy Policy describes how MailToLeaf2 (the “Application”) accesses, uses, stores, and protects Google user data. The Application is a private desktop tool intended solely for its owner's personal use.

1. Google user data accessed

With the owner's explicit authorization, the Application uses Gmail read-only access. Depending on the owner's configuration, it may access:

  • the Gmail account address used to confirm the authorized account;
  • message identifiers and mailbox history information;
  • message metadata, including sender name, sender address, subject, date, and labels; and
  • the body text of messages from senders specifically selected by the owner.

2. How Google user data is used

The Application uses this data only to:

  • detect relevant new or changed Gmail messages;
  • filter messages according to sender rules configured by the owner;
  • render sender names, subjects, and selected message content into local PNG images; and
  • maintain local state needed to prevent unnecessary duplicate rendering.

The Application does not send, modify, move, or delete Gmail messages and does not use Gmail data for advertising, profiling, credit decisions, or artificial-intelligence model training.

3. Storage and processing

Processing occurs on the owner's Mac. OAuth authorization tokens, configuration files, local state, generated images, and operational logs are stored locally on that computer. The Application does not operate a remote email-processing server and does not upload Gmail message data to the developer or to third-party analytics services.

The owner may manually or locally transfer generated images to a personal e-ink device. Such a transfer is initiated and controlled by the owner and is not a disclosure of Gmail data to the developer.

4. Sharing and disclosure

Google user data is not sold, rented, shared with advertisers, or disclosed to unrelated third parties. Data is exchanged only with Google APIs as necessary to provide the functions authorized by the owner.

5. Retention and deletion

Data remains under the owner's control on the local computer. Generated images may be replaced as newer messages are processed. The owner can delete local images, logs, application state, and OAuth token files at any time. The owner can also revoke the Application's Google access from the Google Account security settings.

6. Security

The Application uses Google's OAuth 2.0 authorization flow and stores the resulting token locally. No method of storage is completely risk-free, so the owner is responsible for maintaining the security of the Mac account, disk, backups, and any personal display device receiving generated images.

7. Google API Services User Data Policy

The Application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Changes to this policy

This policy may be updated if the Application's functionality or data practices change. The effective date at the top of this page will be updated when changes are made.
