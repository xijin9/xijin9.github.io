Personal Gmail Ink Monitor

Personal Gmail Ink Monitor is a private desktop utility used only by its owner. It checks the owner's Gmail account for messages from senders selected by the owner and renders relevant sender names, subjects, and message content into local PNG images for a personal e-ink display.

The application runs on the owner's Mac. It does not offer public user accounts, advertising, analytics, or a hosted email-processing service.

How it uses Gmail

  • Reads Gmail data with read-only permission.
  • Checks only for messages needed by the owner's configured monitoring rules.
  • Creates local summary or full-message images for the owner's personal display.
  • Does not send, modify, move, or delete email.

Data handling

Gmail data, OAuth tokens, configuration, generated images, and operational state remain on the owner's local computer. Gmail data is not sold, used for advertising, or shared with third parties.
